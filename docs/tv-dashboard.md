# TV de preparación

`/tv` shows non-beverage lines from completed sales only. The server reads the last 15 minutes of orders with the existing administrator session/RLS. It projects immutable receipt items into quantities, product names, selected extras and notes; no customer contact details or financial figures are returned to the TV. Category `Bebidas` is excluded (case/accent/space normalized); other categories are included. Missing categories/details fail visibly rather than silently omitting a potentially needed item.

Orders are oldest first. `orders.created_at` is the paid sale insertion time (including CLIP settlement), not the draft/quote time. At exactly created_at + 15 minutes the order leaves the display. This runs every second in the client even if the next API request fails, and the server filters the same window. Expiry never writes to the database or changes payment, preparation, inventory, receipts or print journals. Reload/reconnect cannot restart the original timer. The rolling window spans midnight.

New orders and cancellations are fetched automatically every five seconds; no manual refresh or POS completion button is needed. Up to six orders appear per page; overflow pages rotate every ten seconds and tall pages scroll automatically. Expired cards disappear and the remaining queue reflows. Network failures retain unexpired last-known orders with a warning; an empty stale queue never claims that preparation is caught up. Authorization loss clears the screen and requires administrator sign-in.

Use an administrator Edge profile separate from Caja, Windows extended display, wireless HDMI and fullscreen. Keep the PC awake and online. No database migration is needed. This is a local implementation, not evidence of café deployment or physical wireless-HDMI acceptance. Install using the normal reviewed release process; returning to the previous app version restores the sales dashboard without a database rollback.

Checks: targeted domain/server/UI tests cover mixed tickets, drink-only exclusion, pending/cancelled exclusion, exact 15-minute expiry without network responses, refresh persistence, midnight, pagination, read failure, missing categories and role checks. Typecheck, lint and isolated production build are required. Preview HTML/PNGs use synthetic orders rendered through the actual view.
